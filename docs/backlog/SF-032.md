# Title
SF-032 — Build Bookmarks UI and IFrame API seek integration

# Problem statement
Users need a way to visually mark their current playback time and click existing bookmarks to jump instantly to that section of the video.

# Scope
Create the frontend React components to interact with the Bookmarks API and the YouTube IFrame player.

# Technical requirements
- Add a "Bookmark Current Time" action button near the player.
- Build a `BookmarkList` component displaying saved bookmarks formatted as readable timestamps (e.g., `12:34`).
- Extract the current timestamp imperatively from `react-youtube` instance (`player.getCurrentTime()`) on bookmark creation.
- On bookmark click, imperatively seek the player to the saved `position_seconds` using `player.seekTo()`.

# Database/API/UI boundaries where applicable
- Frontend UI layer interacting with the previously built `/api/bookmarks` and the YouTube IFrame JavaScript API.

# Acceptance criteria
- Clicking "Bookmark Current Time" successfully saves a bookmark for the current exact video position.
- Saved bookmarks are rendered in a list.
- Clicking a saved bookmark instantly seeks the active YouTube video to that time.

# Testing requirements
- E2E Playwright test simulating bookmark creation and verifying the list updates.
- Unit testing timestamp formatting utility functions.

# Security/RLS requirements
- HTML input sanitization for bookmark labels if user input is allowed.

# Explicit out-of-scope items
- Backend API creation (handled in SF-031).
- Analytics or tagging.

# Dependencies
- SF-031 — Implement Bookmarks API and Service layer

# Definition of Done
- Component handles all states (Empty, Loading, Error, Success).
- Keyboard accessibility maintained (tab navigation, aria-labels for buttons).
- Seek-to integration is smooth and does not cause iframe reloads.
- PR is reviewed and merged.
